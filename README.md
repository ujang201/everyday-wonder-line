# Everyday Wonder: The Shadow That Walked Ahead

One original sentence about a small moment of wonder in everyday life: a shadow reaching a street corner a step before its owner and walking one step alone, as if it had somewhere better to be. The ordinary turns strange in a single read — the shadow, the most familiar companion, briefly acts on its own.

## The entry

> My shadow got to the corner before I did and walked one whole step alone, as if it had somewhere better to be.

## Run

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set). The output is deterministic: every run writes the same bytes. The program also self-checks the gate itself — it refuses to write a line outside 1–200 characters, and it requires exactly one sentence ending in a full stop.
